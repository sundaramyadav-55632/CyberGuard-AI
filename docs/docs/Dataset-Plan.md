# Dataset Plan – CyberGuard AI

## 1. Phishing Detection Datasets
We plan to explore publicly available phishing datasets containing suspicious URLs, phishing emails, and related features for phishing analysis.

Potential sources:
- Phishing URL datasets
- Phishing email datasets
- Public cybersecurity research datasets

## 2. Deepfake Detection Datasets
We plan to evaluate publicly available datasets containing authentic and manipulated media.

Potential datasets:
- FaceForensics++
- DeepFake Detection Challenge (DFDC)
- Celeb-DF

## 3. Purpose
The datasets will support future experimentation, testing, and evaluation of the phishing and deepfake analysis modules.

## 4. Current Status
Dataset planning is completed as part of Sprint 01. Dataset selection, preparation, preprocessing, and experimental use are pending.

## 5. Data Handling
Datasets will be selected based on relevance, availability, licensing, quality, and suitability for academic experimentation.
