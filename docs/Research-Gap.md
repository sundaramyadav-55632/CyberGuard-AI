# Research Gap

Existing cybersecurity solutions commonly focus on phishing detection and deepfake detection as separate analysis tasks. Phishing detection mainly examines suspicious emails, URLs, and communication patterns, while deepfake detection focuses on manipulated images, videos, or audio.

This separation can make it difficult for ordinary users to access and understand both types of digital threat analysis through a single workflow.

CyberGuard AI explores this gap by proposing a unified platform that combines phishing-related analysis and deepfake/media analysis, with understandable risk indicators and warnings through a common interface.

The project focuses on integration, usability, and risk communication rather than proposing an entirely new detection algorithm.
