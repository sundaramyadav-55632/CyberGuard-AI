# Literature Review

## 1. Phishing Detection
Existing phishing detection approaches use email content analysis, URL features, domain reputation, machine learning classifiers, and natural language processing to identify suspicious messages and links.

## 2. Deepfake Detection
Deepfake detection research focuses on identifying manipulated media using image analysis, facial inconsistencies, video artifacts, audio characteristics, and machine-learning or deep-learning models.

## 3. Existing Approaches
Most approaches focus on detecting a specific threat type, such as phishing emails, malicious URLs, manipulated images, or fake videos. Different detection methods and datasets are used depending on the media and threat being analyzed.

## 4. Relevance to CyberGuard AI
The reviewed approaches provide the foundation for exploring a unified workflow that brings phishing analysis and deepfake/media analysis together in a single platform.
