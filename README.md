# CyberGuard AI
### A Unified Approach to Phishing and Deepfake Threat Analysis

## Overview
CyberGuard AI is a capstone project focused on phishing attacks and deepfake media. The project aims to explore a unified workflow for analyzing suspicious emails, URLs, images, videos, and audio to help users understand potential digital threats.

## Problem Statement
Phishing attacks and manipulated media are increasingly used to deceive people and exploit trust. While phishing detection and deepfake detection are often handled separately, this project explores bringing both forms of analysis into a unified platform.

## Objectives
- Study phishing-related emails and suspicious URLs.
- Explore deepfake analysis for images, videos, and audio.
- Design a unified analysis workflow.
- Present risk indicators and warnings in an understandable way.
- Develop a modular system architecture.

## Proposed Technology Stack
- **Frontend:** React.js, HTML, CSS
- **Backend:** Python, FastAPI
- **API:** REST API
- **Analysis:** Machine Learning, NLP, OpenCV and Deep Learning

## Project Status
- Sprint 01: Research, problem definition, objectives, requirements and system design completed.
- Sprint 02: Initial prototype setup started.
- Backend integration, detection models and performance evaluation are planned development activities.
